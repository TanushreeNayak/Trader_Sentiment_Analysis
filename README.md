# Trader_Sentiment_Analysis

**Project objective:**  This project analyzes the relationship between **Bitcoin market sentiment** and **trader performance** by combining the **Fear & Greed Index** with historical trading data from **Hyperliquid**. It uncovers patterns in profitability, win rate, and trade size across different market sentiment conditions such as Fear, Greed, and Extreme Greed. The analysis reveals actionable insights that can help traders optimize position sizing and improve risk management. An interactive **Streamlit dashboard** was developed to visualize trader behavior and support smarter data-driven trading strategies.

**Methodology**
1. merge + analysis + dashboard
2. insights
3. Extreme Greed → highest avg profit
4. Fear → highest trade size

**How to run**
pip install -r requirements.txt
streamlit run app.py
